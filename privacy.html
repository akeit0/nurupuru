日本語

本アプリは、利用者のプライバシーを尊重します。

  1. 画像・動画データ

    編集対象の画像・動画はブラウザ内で処理されます。運営者はこれらのファイルを収集・保存しません。

  2. 端末内の設定

    言語・テーマ・表示設定は、ブラウザのlocalStorageに保存します。これらの設定を運営者に送信することはありません。画像・動画をlocalStorageに保存することはありません。

  3. アクセス解析・広告

    本アプリはアクセス解析ツールや広告を使用していません。追跡を目的としたCookieも使用しません。

  4. GitHub Pagesについて

    GitHub Pagesで公開されるバージョンでは、GitHubがセキュリティ等の目的でアクセス元のIPアドレスを記録・保存します。

  5. お問い合わせ

    お問い合わせで提供された情報は、回答や必要な連絡のためにのみ使用します。GitHub Issuesでのお問い合わせはGitHub上で処理され、投稿内容が公開される場合があります。

GitHubのプライバシーに関する情報は、GitHub Privacy Statementをご確認ください。

English

This app respects your privacy.

  1. Image and Video Data

    Images and videos are processed locally in your browser. The developer does not collect or store these files.

  2. Local Preferences

    Language, theme and display preferences are stored in your browser's localStorage. These settings are not sent to the developer. Images and videos are not saved in localStorage.

  3. Analytics and Advertising

    This app does not use analytics tools, advertising, or tracking cookies.

  4. GitHub Pages

    For versions hosted on GitHub Pages, GitHub logs and stores visitors' IP addresses for security purposes.

  5. Contact Information

    Information provided through inquiries is used only to respond and communicate when necessary. Inquiries through GitHub Issues are processed by GitHub and may be public.

For more information, please refer to the GitHub Privacy Statement.
