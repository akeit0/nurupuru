編集設定
01ブラシ設定

画像をなぞって動かす範囲を塗ります。マスクボタンで表示を切り替えられます。

0 固定255 動きやすい

塗り重ねても中心の値は変わりません。境界はなめらかにつながります。

色は動きやすさを示します。表示の濃さはキャンバス右上から変更できます。

G つかみ設定

塗った部分をドラッグして引っぱります。離すとバネの反動で揺れます。

キャンバス上の円がつかむ範囲です。

中心からの力の弱まり方を選びます。正規分布は円の外側にも弱い力が続きます。

高くすると指についてきやすくなります。

揺れそのものの材質・戻る速さは 「材質・反動」 で調整できます。
F 輪郭フィット

画像をクリックして領域を選択します。透過画像でも色選択が使えます。

V 移動揺れ

画面全体をドラッグして動かします。移動・停止時の加速度がマスク内に伝わり、慣性で揺れます。

画像を直接つかむ操作ではありません。局所的に引っぱるには G「つかむ」 を選んでください。
H 画面移動

背景は1本指・マウスで位置、スクロールで倍率を調整。Space・2本指は常にキャンバス全体を移動します。

ブラシの詳細設定⌄
ペンの筆圧ブラシサイズに反映します
♪ 揺らし方

好きな動きを選び、「▶ 揺らす」でプレビューできます。

時計回りの円運動。

揺れ方の向きを回転します。0°は元の向きです。

強さは画像幅に対する割合です。

柔らかい設定では大きく伸びる場合があります。

02 材質と反動

材質を選んで、やわらかさと余韻を調整します。

小さくすると硬く、大きくすると柔らかくなります。

高くすると形がつぶれにくくなります。

小さくすると余韻が長く、大きくすると早く静まります。

高くすると塗っていない部分が動きにくくなります。

計算品質⌄

大きくすると精度が上がり、負荷が増えます。

WASMが利用できない場合はJavaScriptで計算します。

操作ヘルプ

各ツールの使い方とショートカットを確認できます。

画像の貼り付け（Ctrl / ⌘ + V）
PCではキャンバス上部で貼り付け先を「前景」「背景」から選び、Ctrl / ⌘ + Vで読み込みます。スマホではメニュー内の「画像を貼り付け」「背景画像を貼り付け」を使います。画像そのものをコピーしてください。
ブラシ・消しゴム（B / E）
指定した動きやすさ（0〜255）を塗ります。0は強く固定、255は動きやすい状態。低い値でも上塗りできます。消しゴムは0に戻します。青→黄→赤で値を表示し、表示の濃さは動きに影響しません。
ブラシの右ドラッグは消しゴムとして使えます。
輪郭フィット（F）
選びたい物体の内側をクリック・タップして離すと、輪郭に沿ってマスクを追加します。
つかむ（G）
マスクを塗った部分をドラッグして引っぱります。離すと反動で揺れます。「力の分布」で1乗・2乗・正規分布を選べます。
右ドラッグで移動揺れを使えます。
移動揺れ（V）
画面をドラッグすると、移動・停止の加速度で画像が揺れます。
画面移動・ズーム（H / Space）
Hで移動ツールを選び、対象をキャンバス・背景から選べます。ドラッグで移動、スクロールで選択した対象を拡大縮小。Space＋ドラッグ・2本指は常にキャンバス全体の移動・ズームです。
揺らし方・材質
「揺らし方」で自動揺れの種類・強さ・速さ、「材質・反動」でやわらかさ・減衰・固定力を調整。「▶ 揺らす」（P）で自動揺れを開始・停止します。
表示・やり直し
ヘルプ横でテーマ・背景・操作範囲の円を切り替えます。↻で変形をリセット。Mでマスク表示、0で全体表示。Ctrl / ⌘ + Zで元に戻す、Ctrl / ⌘ + Shift + Zでやり直す。1 / 2 / 3で設定タブを切り替えます。
