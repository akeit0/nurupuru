# 物理計算の構成

`src/physics.js` の `SoftMesh` が画像領域を三角形メッシュに分割し、頂点の位置と速度を保持します。JavaScriptとC製WASMは同じ倍精度の計算と頂点の更新順序を使います。

## マスクと入力

マスクの赤チャンネルが0〜255の動きやすさ、緑チャンネルが塗られた領域を保持します。各頂点は周辺の4点からマスクをサンプリングします。更新領域が分かるときは、その領域に影響する頂点だけを更新します。

マスクの値は固定力と入力の伝わり方に作用します。「つかむ」は選んだ範囲の頂点に目標位置を与えます。「移動揺れ」は画面の加速度から速度変化を与えます。自動揺れは小さな行・列の波形テーブルを使って目標を準備します。

## ソルバー

時間刻みは1/120秒です。サブステップで目標を準備し、慣性・固定・つかむ操作と三角形の弾性エネルギーを組み合わせます。

各頂点を順に更新するVertex Block Descentを使い、残差が目標へ達するか、設定した反復上限で終了します。頂点の更新では線探索を行い、三角形の面積が反転する候補を避けます。変形の行列式に対する対数項は反転の手前で大きくなります。

予測位置のエネルギーを上界で判定できるときは、その値を使います。判定できない場合はエネルギーを直接評価します。位置・変形行列・速度・残差は対応するテストで確認します。

## WASM

`src/physics-wasm.js` が配列をメッシュ専用のWASMメモリへ配置し、Cカーネルへ接続します。モジュールは共有できますが、インスタンスと可変メモリは共有しません。WASMの生成・初期化を利用できない場合はJavaScriptで計算します。

`src/wasm/physics.c` を編集したら `npm run build:wasm` で `physics-binary.js` を再生成します。浮動小数点の積和演算と自動ベクトル化を無効にし、JavaScriptとの計算順序を合わせています。

## 描画

WebGL2は解いた頂点の位置をそのまま使います。画像・背景のテクスチャは必要なときだけ更新し、マスクの変更は部分更新します。静止した画面は物理計算と再描画を停止します。操作、設定変更、再生開始で再開します。
